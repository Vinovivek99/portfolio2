- index.html

## GitHub Pages
Upload all four files to the repository root. Do NOT put `profile.png` inside an `assets` folder.
The image is referenced as:
`./profile.png`

Then enable GitHub Pages from Settings → Pages → Deploy from branch → main → /(root).

The site includes:
- Fixed/sticky hero portrait
- Scroll reveal animations
- Hero portrait parallax
- Designed About, Skills, Experience, Certifications and Contact sections
- Responsive mobile layout
